# QuickHack and Netrunning

## Setup

Enable QuickHack in Module Settings and disable the standalone Pneuma Quickhack module. Configure availability as **RAW**, **Must Buy QuickHack**, or **Must Be Loaded in Equipped Cyberdeck**. These are module setting labels, not a claim that all integrated QuickHack mechanics are standard core rules.

Equipped-deck availability follows native installed-program lists; REZ is not proof that a program is loaded. Missing module content can be created without replacing existing inventory. Custom hacks, Net Action spending, Neuroport requirements and Self-ICE/Passwall automation remain manual/deferred.

## Jack In and hack

1. Add the runner and target tokens to the intended active, started scene encounter.
2. Select the runner, open the target controls and Jack In.
3. Resolve the native Interface roll and detection. Checks require range within 25 grid squares and wall sight to sampled target points.
4. Use a QuickHack while the tracked connection is active and availability permits it. The roll must beat its DV.
5. Resolve downstream damage, disablement choices or guidance on the result card.

Netrunners detect automatically; other targets oppose detection with WILL, and detection ties favor detection. Losing line of sight blocks actions without disconnecting the link. Successful noisy hacks reveal awareness; Lure keeps its silent-success exception.

## Disconnect or eject

**Jack Out** voluntarily disconnects and permits a fresh Jack In later. A detected target can use Force Out or right-click Neural Intrusion and choose the incoming runner. Target Concentration opposes runner Interface; ties favor the runner. Successful ejection blocks that runner from re-Jacking In for the encounter.

Multiple detected connections have separate ejection choices. Deleting awareness chat does not erase the saved connection or awareness. Existing effects are not universally undone by disconnecting or disabling QuickHack.

## Effect coverage

| Hack | Automated or supported result | Still managed at the table |
| --- | --- | --- |
| Impair Movement | Timed MOVE penalty. | Tactical/action choices. |
| Slow | Native 1d6 reduction and timed MOVE effect. | Tactical/action choices. |
| Sonic Shock | Temporary native Damaged Ear and Deafened. | Sensory and communication rulings. |
| Overheat | Strong fire; 4 direct HP at turn end without stacking. | Extinguishing Action. |
| Short Circuit | Three-item timed disablement. | Configured chooser decision. |
| Cyberware Malfunction | One-item timed disablement; allowed host cascade. | Chooser decision. |
| Synapse Burnout | Native damage control. | Explicit damage application. |
| System Reset | Sleep/Unconscious plus Prone; wake behavior. | Wake/Get Up Action costs. |
| Lure | Roll/result and silent-success handling. | Movement and behavior. |
| Puppet | Roll/result guidance. | Command and target actions. |
| Shard Ejection | Roll/result guidance. | Chipware/inventory change. |

Matching movement effects refresh duration and preserve the stronger penalty rather than stacking duplicate penalties.

## Outside combat and visibility

Outside combat, Jack In and Force Out can be roll/chat-only with the connection and consequences managed manually. Tracked QuickHack execution requires an encounter connection.

The GM configures message audiences, totals and identity under QuickHack Configure. Ejection reuses saved awareness routing. Visual Tools can render optional Neural Intrusion glitches; Combat Tools owns the connection, status and Eject controls.
