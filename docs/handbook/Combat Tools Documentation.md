# Combat Tools Documentation

Pneuma's Combat Tools coordinates attacks, defender responses, damage, area effects, grapples and netrunning between characters in Foundry. Use native Cyberpunk RED sheets for general character management.

> [!info] Documentation baseline
> Source-reviewed on **2026-09-26** against the local Combat Tools working tree. Its manifest reports **0.9.0**, Foundry **v12** (verified **12.343**), Cyberpunk RED Core and required **libWrapper**. The working tree contains additional uncommitted changes. These notes describe that source snapshot; they do not establish which build is installed in your world or certify live multiplayer behavior. ## Four distinctions to keep clear

1. **Rolling is not applying.** A hit or damage total does not by itself finish HP, armor, injury or effect application.
2. **A reminder is not an Action ledger.** Players and GM still adjudicate Actions, Net Actions, cover and many movement obligations.
3. **Presentation is personal; campaign rules are shared.** Changing HUD placement does not change another user's display or the combat rules.
4. **A saved action belongs to its original context.** Switching the tracker or starting a new encounter does not move an old pending action into it.
