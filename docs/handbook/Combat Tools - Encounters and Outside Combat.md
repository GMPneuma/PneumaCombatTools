# Encounters and Outside Combat

## Which encounter is used?

New actions use the **active, started encounter for their scene**. Viewing a different encounter in the Combat Tracker does not select it for Combat Tools. The exact participating tokens matter; another token of the same actor does not substitute.

If several active, started encounters qualify for the scene, the action stops for the GM to resolve the ambiguity. Scene-less encounters can qualify through their combatant tokens' scenes.

Saved actions keep their original encounter, reset generation, scene and participants. Switching active encounter does not move them. Ending/resetting/deleting that encounter, moving it to another scene or removing required participants can invalidate unfinished actions. Correct the context and start a new action rather than treating an old card as current.

## What works outside combat?

| Workflow | Outside-combat behavior |
| --- | --- |
| Ordinary targeted attack and RAW defense | Can run without tracked combat when other requirements are met; no encounter allowance bookkeeping. |
| Area attacks | Can use outside-combat context when otherwise eligible; combat movement budgets and encounter-only effects are unavailable. |
| Grappling | Scene-scoped relationship; timing is table-managed. |
| Jack In / Force Out | Can be roll/chat-only; connection tracking and consequences remain manual. |
| QuickHack execution | Requires a tracked connection in a started encounter. |
| EMP/cyberware disablement request | Requires the proper started combat. |
| Homebrew ranged-evasion accounting | Requires participants in a started encounter. |
| Movement counters and turn advancement | Require active encounter/turn context. |
| Manual rolls, damage and group checks | Available subject to permissions and any attached effect's requirements. |
| Biomonitor, notifications and indicator editor preview | Do not inherently require a started encounter. |
| Temporary supported effects | Can use game-time durations outside combat. |
| Automatic fire ticks | No automatic out-of-combat ticking. |

An outside-combat action is not silently adopted when combat starts later. A scene grapple or manual Jack-In needs deliberate table handling if you transition to tracked combat.

## Cleanup and shared actors

Temporary consequences retain their originating clock and ownership. Encounter cleanup should not remove preexisting permanent conditions or another encounter's causes. Linked tokens still share their actor's native HP/effects; separate token context does not create separate actor health pools.

Actor-only operations reject ambiguous duplicate actor tokens instead of guessing. Synthetic actors retain their exact token identity. Selected-recipient damage from a tracked exchange requires membership in that same encounter.
