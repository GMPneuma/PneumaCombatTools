# Manual Rolls and Group Checks

Click the die beside chat's roll-mode selector to open **Manual Rolls**. Arrow keys navigate; Escape closes. Normal roll visibility is respected, except Group Check requests are deliberately shared cards.

| Entry | Use |
| --- | --- |
| Damage | Label, 1d6–8d6, additive modifier and native location/options. Roll, then select and explicitly apply to a recipient. |
| Critical Injury | Choose head/body, roll the native table and apply the injury to an eligible selected actor. |
| Cyberpunk Roll — Standard | Native Cyberpunk d10 behavior, including natural-10 Critical Success and natural-1 Critical Failure. |
| Cyberpunk Roll — Custom | 1–20 dice, 1–100 sides and an additive modifier; no native Cyberpunk critical behavior. |
| STAT Roll | Selected owned actor or assigned Character; 1d10 must be strictly below the current prepared STAT. Ties fail; no critical extra die. |
| Group Check — GM | Request a native skill roll from selected players with assigned Characters, with an optional visible/hidden DV. |

## Apply manual damage or injury

Manual damage always exposes Interact With Armor and Half Armor SP, plus the shared Add Effects slots and selected-target application. The modifier adds to the total, not the number of dice. Check the receipt after applying.

A standalone critical-injury table roll applies the rolled injury with native duplicate handling. Do not assume it also applies attack damage or injury bonus damage; manage any required separate damage deliberately.

## Request a group check

1. As GM, choose Group Check, the skill, participating players and optional DV.
2. Choose whether the card shows the DV and submit the request.
3. Each player clicks their row's Roll control and completes the native skill dialog.
4. The card moves from Waiting/Rolling to the inline result. If a DV is set, the total must exceed it; ties fail.
5. Click a total to expand/collapse native roll details and modifiers.

Results do not automatically apply consequences to actors. The GM can release/reset abandoned claims using the card's recovery controls. Hidden DV is a presentation option, not protected client-data storage.
