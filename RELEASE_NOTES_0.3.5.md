## Combat Tools 0.3.5

- Streamlined AoE settings with collapsible profiles and live shape summaries.
- AoE attack Dice So Nice animation reveals the existing roll after all evasion responses.
- Shared damage uses blood-drop/ lightning controls; applied results collect below the damage roll. Area visibility controls are GM-only.
- Self CTH uses the standard token-HUD column, with an always-available Alert HUD toggle and a D10 initiative button for installed, functional speedware.
- Movement Reset hides the counter and start marker until movement resumes.
- Thrown weapon names use the list width, item markers sit below names, and grenades appear directly in the list.

Requires Foundry v12, Cyberpunk RED and libWrapper. Live multiplayer verification remains pending; special grenade effects remain manual.
